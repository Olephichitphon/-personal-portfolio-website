## 🚀 English Version

### Project Overview
**Ole Design** is a high-end personal portfolio website built for a professional freelance web developer. It showcases technical skills, past projects, and core business values with a focus on high performance, modern aesthetics, and business results.

### ✨ Key Features
- **Modern UI/UX**: Professional and premium design using a sleek dark/light theme.
- **Interactive Animations**: Smooth transitions and scroll-driven effects powered by **Framer Motion**.
- **Dynamic Content**: Integrated with **Sanity.io** (Headless CMS) for easy content management.
- **Performance Optimized**: Built with **Vite** for ultra-fast loading and development.
- **Responsive Design**: Mobile-first approach ensuring perfect display on all devices.
- **SEO Ready**: Built-in technical SEO foundations to help improve search rankings.

### 🛠️ Tech Stack
- **Core**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS & Vanilla CSS
- **Animation**: Framer Motion
- **CMS**: Sanity.io
- **Icons**: DevIcon / Custom SVGs
- **Deployment**: Vercel

### 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd react-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Environment Variables:**
   Create a `.env` file in the root directory and add your Sanity credentials:
   ```env
   VITE_SANITY_PROJECT_ID=your_project_id
   VITE_SANITY_DATASET=production
   ```

4. **Run development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```

**Ole Design** เป็นเว็บไซต์พอร์ตโฟลิโอระดับพรีเมียมสำหรับนักพัฒนาเว็บไซต์อิสระ (Freelance Web Developer) ที่เน้นการนำเสนอทักษะทางเทคนิค ผลงานที่ผ่านมา และคุณค่าหลักในการทำธุรกิจ โดยมุ่งเน้นที่ประสิทธิภาพการทำงานสูงสุด ความสวยงามทันสมัย และผลลัพธ์ทางธุรกิจที่จับต้องได้

### ✨ คุณสมบัติเด่น
- **UI/UX ทันสมัย**: ดีไซน์ระดับมืออาชีพที่ดูพรีเมียม พร้อมการจัดการธีมที่ลงตัว
- **แอนิเมชันที่น่าสนใจ**: การเปลี่ยนหน้าและเอฟเฟกต์ขณะเลื่อนหน้าจอที่ลื่นไหลด้วย **Framer Motion**
- **การจัดการเนื้อหาแบบไดนามิก**: เชื่อมต่อกับ **Sanity.io** (Headless CMS) เพื่อให้ง่ายต่อการอัปเดตผลงาน
